# Fiche Chrome Web Store (à copier-coller)

**Nom** : Report de notes vers l'ENT
**Résumé (132 car. max)** : Reporte dans la grille d'évaluation de MBN les notes d'une activité Moodle, classe par classe.
**Catégorie** : Productivité · **Langue** : Français · **Visibilité** : Non répertoriée

## Description détaillée
Marre de ressaisir à la main les notes de Moodle dans MBN ?
1. Connecte-toi à ton Moodle (une seule fois, sans mot de passe stocké).
2. Choisis le cours et l'activité notée : toutes les classes sont chargées d'un coup.
3. Ouvre le devoir dans MBN (onglet « Évaluation »), choisis la classe et clique sur « Saisir dans MBN ».
L'extension remplit la grille élève par élève, avec un indicateur de progression. Elle ne clique jamais sur « Valider » : tu vérifies puis tu valides toi-même.
Gratuit, sans compte, sans serveur : tout reste dans ton navigateur. Aucune donnée n'est envoyée à l'éditeur ni à un tiers.
Extension indépendante, non affiliée à Moodle ni à MBN / Monbureaunumerique.fr.

## Onglet « Pratiques de confidentialité »
- **Objectif unique** : reporter dans la grille d'évaluation MBN les notes d'une activité Moodle.
- **Justification des autorisations** : voir tableau dans PRIVACY.md (reprendre la ligne de chaque autorisation).
- **Code distant** : Non.
- **Données collectées** : cocher « Informations personnelles identifiables » (noms d'élèves) et « Authentification » (jeton Moodle) ; certifier : pas de vente, pas d'usage hors finalité, pas d'usage pour solvabilité/prêt.
- **URL de la politique de confidentialité** : adresse publique de PRIVACY.md (voir étape 2 de la liste).
